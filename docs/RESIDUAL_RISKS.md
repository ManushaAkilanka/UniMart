# Residual Security Risks & Dependency Vulnerabilities

This document records dependency audit findings from `npm audit` across the UniMart server and client codebases, assesses real-world exploitability within the UniMart architecture, and outlines mitigations and upgrade plans.

## Dependency Vulnerability Matrix

| Package | Ecosystem | Severity | Vulnerability / Advisory | Reason It Does or Does Not Affect UniMart | Plan / Status |
|---|---|---|---|---|---|
| `zod` (<4.6.6) | Server (prod) | **High** | [GHSA-mrhx-c7xc-m3w5](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5): Memory exhaustion while validating oversized constrained collections | **Mitigated / Does Not Affect**: Express request payloads are capped at `10kb` (`express.json({ limit: '10kb' })`) and string/array properties have strict upper bounds (title <= 120, description <= 2000, body <= 1000) prior to parsing, preventing large collections from consuming CPU/memory. | **Accepted Risk**: Planned upgrade to Zod v4+ following full schema compatibility testing. |
| `nodemailer` (<=10.1.3) | Server (prod) | **High** | [GHSA-mm7p-fcc7-pg87](https://github.com/advisories/GHSA-mm7p-fcc7-pg87), [GHSA-c7w3-x93f-qmm8](https://github.com/advisories/GHSA-c7w3-x93f-qmm8): SMTP header/command injection via CRLF in envelope & addressparser | **Mitigated / Does Not Affect**: All email inputs (recipient, verification codes, subjects, and titles) pass through `validateRecipient()` and `sanitizeHeader()` which strip all `\r` and `\n` characters before dispatching to Nodemailer. Recipients are strictly restricted to `.ac.lk` university emails. | **Accepted Risk**: Planned upgrade to `nodemailer >= 10.6.1` in the next scheduled dependency refresh. |
| `minimatch` (7.0.0 - 11.0.0) | Server (dev) | **Moderate** | [GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249): Potential ReDoS via globparts amplification | **Does Not Affect**: Transitive development dependency via `nodemon`. Not loaded, executed, or bundled in production. | **Accepted Risk**: Development-only dependency. Will update automatically with future `nodemon` releases. |
| `@vitest/mocker` / `vitest` | Server (dev) | **Moderate** | [GHSA-qxg6-89mg-rqv8](https://github.com/advisories/GHSA-qxg6-89mg-rqv8): Code injection via unauthenticated mock registration | **Does Not Affect**: Vitest is a testing framework executed only in local developer environments and CI pipelines. It is never exposed to network requests or production traffic. | **Accepted Risk**: Test environment only. Upgrade scheduled with Vitest minor release. |
| `react-router` / `react-router-dom` (6.0.0 - 7.17.0) | Client (prod) | **Moderate** | [GHSA-wrjc-x8rr-h8h6](https://github.com/advisories/GHSA-wrjc-x8rr-h8h6), [GHSA-337j-9hxr-rhxg](https://github.com/advisories/GHSA-337j-9hxr-rhxg): Open redirect via backslash & SSR hydration constructor injection | **Does Not Affect**: UniMart is a Client-Side Rendered (CSR) Single Page Application via Vite; no SSR hydration exists. URL redirects on login and OAuth callbacks are validated against relative paths and `CLIENT_URL`. | **Accepted Risk**: Planned upgrade to React Router v7 in frontend architecture update. |
| `dompurify` (<=3.4.16) | Client (prod) | **Moderate** | [GHSA-55q2-fjhq-7xh7](https://github.com/advisories/GHSA-55q2-fjhq-7xh7): IN_PLACE hook removal leaves detached subtree executable | **Does Not Affect**: UniMart uses standard default sanitization (`DOMPurify.sanitize(escapeHtml(...))`) on plain text chat messages without custom `IN_PLACE` hooks or XML/SMIL configurations. | **Accepted Risk**: Planned upgrade in next routine `npm update dompurify`. |
